Como usar o modelo em LaTeX (pelo Overleaf)

Nunca usou LaTeX? Não precisa instalar nada no computador. O Overleaf é um editor de LaTeX que roda direto no navegador — você faz upload do arquivo .tex do modelo, edita o texto e o PDF é gerado automaticamente ao lado.

Se preferir, todos os modelos também têm versão em Word (.docx), com o mesmo conteúdo e formatação — o LaTeX é só uma opção para quem já tem familiaridade ou quer aprender. Veja em Modelos.

Passo a passo

  1. Crie uma conta gratuita no Overleaf

    Acesse overleaf.com e cadastre-se (dá para usar seu e-mail do IFRN ou pessoal). O plano gratuito é suficiente para este modelo.

  2. Baixe o(s) arquivo(s) do modelo

    Na página de Modelos (ou da Mostra de Protótipos), baixe o botão LaTeX do modelo que for usar. Alguns modelos também exigem o arquivo ifrn-logo.png (veja o aviso abaixo) — baixe os dois antes de continuar.

  3. Crie um novo projeto a partir do arquivo

    No Overleaf, clique em New Project → Upload Project e selecione o arquivo .tex baixado. Se o modelo também usa o ifrn-logo.png, depois de criado o projeto arraste esse arquivo de imagem para a lista de arquivos à esquerda, para enviá-lo também.

  4. Aguarde a primeira compilação

    O Overleaf compila automaticamente e mostra o PDF do lado direito da tela. Isso pode levar alguns segundos na primeira vez.

  5. Edite o texto e recompile

    Edite diretamente no painel da esquerda (é onde fica o texto do artigo/relatório). Depois de qualquer mudança, clique em Recompile (botão verde acima do PDF) para ver o resultado atualizado.

  6. Baixe o PDF final

    Quando terminar, clique no ícone de download acima do PDF (ou em Menu → Download → PDF) para salvar o arquivo final que você vai entregar.

Modelos que precisam do ifrn-logo.png: os modelos de Pesquisa Acadêmico-Científica e os da Mostra de Protótipos (apresentação padrão e de orientação) têm o símbolo do IFRN no cabeçalho/capa, então precisam desse arquivo de imagem enviado junto no Overleaf — sem ele, a compilação dá erro. Os modelos de Estágio e Extensão não precisam.

Erros comuns

  • "File not found: ifrn-logo.png" — você esqueceu de enviar o arquivo da imagem junto (passo 3 acima).
  • O PDF não atualiza — clique em Recompile; o Overleaf não recompila sozinho a cada tecla digitada.
  • Texto com acentos aparecendo errado — confira se salvou/enviou o arquivo em UTF-8 (o padrão do Overleaf já é esse; normalmente só acontece se o arquivo foi editado antes em outro programa com codificação diferente).
